Pole Inspection History Dashboard

Project Overview

The Pole Inspection History Dashboard is a web-based application designed to manage and maintain inspection records of electrical poles. It provides an organized platform to monitor pole conditions and access previous inspection details.

Objectives

- Maintain digital inspection records for individual poles.
- Track inspection history and inspector details.
- Monitor electrical wire connection status.
- Simplify inspection record management.

Features

- Search records using pole numbers.
- Filter by inspector name and inspection date.
- Check wire connection status.
- View inspection remarks and observations.
- Add new inspection records.
- Edit and delete existing records.
- Export inspection history as CSV.

Technologies Used

- HTML – Structure of the dashboard.
- CSS – Styling and responsive design.
- JavaScript – Search, filtering, and record management.

How to Use

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Add pole inspection details.
4. Search and filter inspection records.
5. Edit or delete records when required.

Inspection Details

Each record contains:

- Pole Number
- Inspector Name
- Inspection Date
- Wire Connection Status
- Remarks / Observations

Future Enhancements

- Shared cloud database for multiple users.
- QR code-based pole identification.
- Real-time ESP32 connectivity monitoring.
- Automatic inspection alerts.
- User authentication and access control.

Note

The current version stores inspection records in the browser's local storage. A shared database is required for multiple users to access and update the same records.
